THẺ 2

Thả file vào

Ảnh gốc, tài liệu, cả thư mục. Ẩn danh gửi tới 100 MB; đăng nhập để gửi file lớn hơn. File được cắt phần và mã hóa ngay trên máy bạn.

THẺ 3

Nhận link + mã

Một link duy nhất, chìa khóa giải mã nằm sau dấu #, phần đó không bao giờ rời trình duyệt của bạn.

THẺ 4

Chia sẻ qua Zalo

Dán link vào Zalo, Messenger hay email. Người nhận bấm là tải, có xác minh SHA-256 để chắc file còn nguyên vẹn.
