- (decision) Brand personality: Speed + Simplicity + Professional + Minimalist + Friendly. Anti-MLM, honest freemium positioning. WeTransfer's simplicity as primary visual inspiration. Feel professional but accessible, not playful like WeTransfer nor technical like MASV.
- (decision) Form factor: Desktop-first + Mobile-responsive (multi-surface). Primary use case is creative professionals at workstations (Huy video editor, Trang wedding photographer) but mobile management important for on-the-go delivery tracking. WeTransfer simplicity as UX benchmark.
- (decision) Branded delivery page: WeTransfer-style layout with professional polish. Logo top-left, personalization note below, file icon+name+size, prominent download button, ads clearly separated below download for Free tier. Studio chooses solid color or subtle gradient background. Clean, professional, branded handoff experience.

- (decision) Trust UX: Progressive disclosure — lock icon badge for all users + simple 'Encrypting...' label in upload progress. Expandable 'Verify encryption' section for power users with hash + plain-language explanation + DevTools guide.
- (decision) UPDATED Dashboard: Grid view (visual cards/thumbnails for deliveries) — user prefers grid over list. Key at-a-glance: download count + expiry status. One-click Copy Link as primary action.
