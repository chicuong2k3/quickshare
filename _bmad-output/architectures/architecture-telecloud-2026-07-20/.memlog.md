- (decision) AD-1: IStorageProvider extended with R2 methods — LocalDiskProvider throws NotSupportedException for R2-specific ops. Keeps single abstraction, avoids two parallel interfaces.
- (decision) AD-2: Two separate upload start endpoints — /api/uploads/start-local returns chunkSize, /api/uploads/start-r2 returns parts[] with signed URLs.
- (decision) AD-2a: Client biết storage mode qua config constant (deployment-time), không cần discovery endpoint. Blazor app đọc config server-side tại startup, gọi start-r2 nếu mode=r2.
- (decision) AD-3: DI registers R2StorageProvider as IStorageProvider by default. No config-driven switching — environment uses the provider it's deployed with. LocalDiskStorageProvider stays in codebase (deprecated via [Obsolete] attribute) but not wired in new deployments.
- (decision) AD-4: R2 object key naming = uploads/{userId}/{deliveryId}/{fileName}. Only authenticated users can upload to R2 — anonymous users are limited to P2P transfer.
- (decision) AD-5: IStorageProvider extended with high-level use-case methods (B). InitiateUploadAsync returns all presigned part URLs in one call. CompleteUploadAsync verifies + completes. GetDownloadUrlAsync returns signed GET URL. DeleteObjectAsync for cleanup.
- (decision) AD-6: Download dùng chung endpoint — GET /api/downloads/{code}. DownloadDeliveryHandler gọi IStorageProvider.GetDownloadUrlAsync() được override bởi R2 trả signed URL, serve 302 redirect. LocalDiskProvider vẫn stream chunks qua GetChunkAsync() cho backward compat.
- (decision) AD-6 (corrected): DownloadDeliveryHandler gọi GetDownloadUrlAsync() → trả 302 redirect đến R2 signed URL. Zero server egress cho download. LocalDiskProvider.GetDownloadUrlAsync() throw NotSupportedException vì đã deprecated.
- (decision) AD-7: Delivery.StoragePath lưu full R2 object key = uploads/{userId}/{deliveryId}/{fileName}. Null = local disk backward compat. R2Options config section thay thế StorageOptions.
- (decision) AD-8: Design principle — every decision prioritizes bandwidth/cost optimization. CompleteUploadAsync calls CompleteMultipartUploadAsync directly (no ListParts pre-check). HeadObjectAsync for single-PUT verification.
- (decision) AD-9: SSE-S3 encryption at rest — R2-managed AES-256-GCM keys, zero config overhead. Client-side PIN encryption is independent layer on top.
- (decision) AD-10: uploadId = R2 multipart upload ID, stored in UploadSession.R2UploadId new column. StartR2UploadHandler writes it, CommitR2UploadHandler reads it.
- (decision) AD-11: Error handling — R2StorageException wrapping AmazonS3Exception, handlers return 502/400. No fallback to local disk. R2StorageProvider may retry transient S3 errors internally.
- (event) Reviewer gate fixes: .NET 9→10, AWSSDK.S3 v4 + R2 flags, SSE-S3→automatic encryption (R2 doesn't support SSE headers), added AD-10 (uploadId lifecycle), AD-11 (error handling), tightened AD-4 (shared key utility), AD-7 (write timing)
- (event) Spine finalized. 11 ADs, Stack table corrected (net10.0, AWSSDK.S3 v4), 2 reviewer-gate passes applied.
