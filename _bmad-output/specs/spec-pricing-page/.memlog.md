---
topic: Pricing revamp — Free/Pro/Studio with config-driven limits, competitive vs Google Drive & Telegram
updated: 2026-08-02T12:00
---

- (direction) User wants pricing competitive vs Google Drive (15 GB free) and Telegram (2 GB/file, unlimited storage). P2P is same-WiFi only — not the main product. Cloud is the real differentiator.
- (decision) Strategic pivot: stop competing on storage GB (unwinnable vs Google/Telegram). Compete on transfer capability: file size, speed, lossless, no-recipient-account, E2E, share-before-upload-completes.
- (decision) Free tier becomes "instant delivery" — 5 GB/file, 2-hour TTL, no long-term storage. Files auto-delete. Ads monetize. This makes storage cost near-zero (₫0.27/GB at 30-min average lifetime).
- (decision) Paid tiers (Pro 30-day, Studio 90-day) provide real cloud storage. Pro: ₫49K/mo, Studio: ₫199K/mo.
- (decision) All limits configurable in appsettings.json under Pricing:Limits. PlanTierLimits reads from IConfiguration with fallback defaults. No hardcoded magic numbers.
- (decision) Expiry unified under TimeSpan — `GetMaxExpiry(plan)` returns TimeSpan. Free uses hours, paid uses days.
- (decision) Lossless quality is a key differentiator: "What you send is what they receive — byte for byte." No compression, no re-encode. Already true architecturally (we never touch file bytes), now marketed.
- (decision) Download speed is already optimal: Cloudflare R2 presigned URLs = direct binary transfer via global edge network. No JSON overhead on file bytes. No server bottleneck. Messenger uses binary protocol for chat messages (KB-scale, 30% JSON overhead matters); our files are GB-scale where 2 KB JSON metadata is 0.00004% — binary protocol not needed.
- (decision) SPEC-pricing-page and pricing-tiers.md rewritten for current Free/Pro/Studio model. Old Telegram-backed WeTransfer-style tiers (Starter/Ultimate/Teams/Enterprise) archived.
- (event) Implementation plan created at docs/superpowers/plans/2026-08-02-pricing-revamp-plan.md.
